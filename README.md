### 🚀 Flagship & Featured Projects

#### 1. [PayGuard AI — Agentic Payment Dispute Intelligence System](https://github.com/KrishanKantAgnihotri/PayGuardAI)
> **Multi-agent LangGraph workflow** that investigates payment disputes (chargebacks), gathers delivery & merchant evidence, calculates fraud risk scores, and generates bank-ready defense dossiers with FIGHT / ACCEPT / ESCALATE recommendations autonomously.

- **🌐 Live Deployed App:** [payguardai-kk.streamlit.app](https://payguardai-kk.streamlit.app/)
- **💻 GitHub Repository:** [`KrishanKantAgnihotri/PayGuardAI`](https://github.com/KrishanKantAgnihotri/PayGuardAI)
- **Key Use Case & Impact:** Chargeback reviews traditionally take 30–45 minutes per claim. PayGuard AI automates the complete lifecycle in seconds using 5 coordinated agents (`Investigation`, `Evidence Collector`, `Risk Scoring`, `Defense Generator`, `Decision Agent`) with cyclic tool-calling over simulated gateway APIs (KYC, velocity patterns, delivery tracking, transaction histories).
- **Stack:** Python, LangGraph, Google Gemini 3.1 Flash-Lite, Pydantic `MessagesState`, Streamlit Fintech UI.
